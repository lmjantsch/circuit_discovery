# Context-Marginal AP (CM-AP) — 회로 발견 regime 에 맞춘 golden reference

GPT-2 small / IOI / train CF 쌍 100개. 스크립트: `experiments/mib/scripts/compute_cmap_gpt2_ioi.py`

---

## 1. 왜 필요한가 — 기존 single-edge AP 의 한계

### 1.1 기존 방식

지금까지 attribution 충실도의 참값으로 **single-edge AP** 를 썼다:

> edge `(u→v)` 하나의 기여분만 corrupt 로 swap, **나머지는 전부 clean** → 실제 forward →
> `I_AP(e) = m(clean) − m(e 만 ablate)`

그리고 `ε = |score − I_AP|` 로 각 기법의 "노이즈"를 쟀다.

### 1.2 측정 결과 (무편향 글로벌, 단위 보정 후)

`golden_ap_global_gpt2_ioi.pt` — 랜덤 1000 edge(모집단 무편향) + 4기법 top-200 union 285개.
score 는 per-token 정규화(`tracer.py: per_sample_scores / n_real`)라 golden 과 단위가 다르므로
평균 프롬프트 길이 **T = 16.35** 를 곱해 단위를 맞췄다 (최소제곱 slope 17.28 로 확인).

| 표본 | method | mean ε | ε/\|I_AP\| | win vs EAP | Spearman |
|---|---|---|---|---|---|
| **랜덤(무편향)** | **EAP** | **0.00072** | **0.290** | — | **0.9713** |
| n=1000 | +FrLN | 0.00082 | 0.330 | 0.259 | 0.8110 |
| | +SM | 0.00109 | 0.439 | 0.248 | 0.8421 |
| | +Bilinear | 0.00186 | 0.746 | 0.127 | 0.7649 |
| **union top-200** | **EAP** | **0.07202** | **0.314** | — | **0.9332** |
| n=285 | +FrLN | 0.07848 | 0.342 | 0.460 | 0.9076 |
| | +SM | 0.07558 | 0.329 | 0.333 | 0.9200 |
| | +Bilinear | 0.14057 | 0.613 | 0.189 | 0.8105 |

**모든 표본에서 plain EAP 가 최소 노이즈.** 표본 편향 때문이 아니다 — 무편향 랜덤에서도 동일.

### 1.3 그런데 CPR 은 정반대다

| gpt2/ioi | EAP | +FrLN | +SM | +Bilinear | 조합 |
|---|---|---|---|---|---|
| log-CPR | **6.15** (최저) | 13.04 | 11.16 | 11.17 | ~15.0 |

**EAP 는 single-edge AP 를 거의 완벽히 순위매기면서(ρ=0.9713) 회로 발견은 최악이다.**
즉 두 지표가 **역상관**한다.

### 1.4 한계의 정체 — regime mismatch

single-edge AP 와 CPR 이 상정하는 상황이 **완전히 다르다**:

| | single-edge AP | CPR 평가 |
|---|---|---|
| 동시에 corrupt 되는 edge | **1개** | 회로 밖 **전부** (`PERCENTAGES=(0.001,…,0.5)` → 최대 99.9%) |
| 각 op 입력의 이동거리 | 작은 δ | **full clean→corrupt 에 근접** |
| bilinear cross 항 | **≡ 0** (operand 하나만 이동) | 큼 (op-gap 0.27~0.83) |
| self-repair/backup 경로 | **살아있음** → 효과 가려짐 | 함께 ablate → 드러남 |

따라서:
1. **EAP 가 이기는 게 구조적이다.** EAP score 는 정의상 single-edge 개입의 1차 테일러항이고,
   섭동이 작아 1차가 이미 ~70% 를 설명한다(ε/\|I_AP\| = 0.29).
2. **모듈은 full-transition 크기로 calibrate** 돼 있어 이 regime 에선 과보정한다.
   실측: joint-AP 에서 midpoint 의 함의 cross `Δ` 는 golden `C` 의 **5.6배**(slope 0.18).
   Bilinear 는 상대 operand 가 아예 안 움직이는 single-edge 에서 보정 대상이 0 이므로 순손실(win 0.089~0.127).
3. **single-edge AP 의 순위 ≠ 회로에 필요한 순위.** self-repair 때문에, 혼자 끊으면 backup 이 보상해
   작아 보이는 edge 가 backup 도 끊긴 회로에선 결정적일 수 있다(반대도 성립).

> 요약: **기존 golden 은 "다른 문제의 정답"이다.** 회로 발견이 요구하는 것은
> "나머지가 대량 ablate 된 상태에서의 한계 효과"인데, single-edge AP 는 "나머지가 전부 clean 일 때의 한계 효과"다.

## 2. 제안 — Context-Marginal AP (CM-AP)

### 2.0 요약 — 왜 single-edge AP 로는 부족하고, 그래서 CM-AP 를 제안하는가

**score 는 "clean→corrupt 로 갈 때 metric 이 얼마나 변할지"를 gradient 로 예측한 1차 근사값이고,
CM-AP 는 그 변화를 실제로 forward 돌려서 측정한 참값이며, Pearson/Spearman 은 이 예측값과 참값이
edge 들 전반에서 얼마나 나란히 가는지를 각각 값/순위로 잰 상관계수다.** 즉 attribution score

$$
s(u\!\to\!v)\;=\;\mathbb{E}_b\!\left[\frac{1}{T_b}\sum_{s,d}\big(a_u^{\text{clean}}-a_u^{\text{corrupt}}\big)_{bsd}\Big(\frac{\partial m}{\partial t_v}\Big)_{bsd}\right]
$$

를 검증하려면 "참값"이 필요한데, 관행적으로 쓰이는 참값인 **single-edge AP**

$$
I_{\text{AP}}(e)\;=\;\mathbb{E}_b\big[\,m(x^{\text{clean}})-m\big(x^{\text{clean}}\;\big|\;\text{patch}(e)\big)\big]
\qquad(\text{그 edge 하나만 corrupt, 나머지는 전부 clean})
$$

은 **edge 의 진정한 기여도를 재기 어렵다**. 이유는 셋이다 — (i) 나머지가 모두 살아 있으므로 **backup 경로가
보상(self-repair)** 해 그 edge 의 기여가 가려지고(실측: norm 매개 ≈ 효과의 14%), (ii) bilinear op
`z = x·y` 에서 operand 하나만 움직이므로 `Δx·Δy ≡ 0` — **모듈이 겨누는 2차 cross 항이 애초에 존재하지 않으며**,
(iii) 무엇보다 회로 발견은 이런 상황에서 작동하지 않는다: CPR 은 상위 `d ∈ [0.001, 0.5]` 만 남기고
**나머지 전부를 ablate** 한 뒤 성능을 재므로, 실제로 필요한 것은 "모두가 clean 일 때의 한계 효과"가 아니라
**"나머지가 대량 ablate 된 상태에서의 한계 효과"** 다. 따라서 우리는 **재는 양(= edge 하나의 한계 효과)은
그대로 두고 배경만 회로 ablation 상태로 바꾼** 참값, **Context-Marginal AP** 를 제안한다:

$$
I_{\text{ctx}}(e\mid d)\;=\;
\begin{cases}
\; m(C_d)\;-\;m\big(C_d\setminus\{e\}\big), & e\in C_d \quad\text{(leave-one-out)}\\[4pt]
\; m\big(C_d\cup\{e\}\big)\;-\;m(C_d), & e\notin C_d \quad\text{(add-one-in)}
\end{cases}
$$

여기서 `C_d` 는 **4기법 평균순위 상위 `d` 비율만 clean 으로 유지하고 나머지를 corrupt 로 ablate 한 문맥**이며
(특정 기법을 우대하지 않기 위한 선택), `m(C_d)` 는 재는 대상이 아니라 **기준점**일 뿐이다. 이 정의는
`d=1` 에서 `I_{\text{ctx}}(e\mid 1)=I_{\text{AP}}(e)` 로 **기존 single-edge AP 에 정확히 환원**되므로,
CM-AP 는 관행적 참값(`d=1`)과 회로 발견 regime(`d\!\to\!0`)을 **하나의 파라미터로 잇는 연속체**가 되고,
`d` 를 낮추며 `\rho\big(s,\,I_{\text{ctx}}(\cdot\mid d)\big)` 를 추적하면 각 기법의 우열이 regime 에 따라
어떻게 달라지는지를 **다른 요인 없이 `d` 만으로** 판별할 수 있다.

구체적으로:

| | 계산 방식 | 비용 |
|---|---|---|
| **score** (예측) | clean·corrupt forward 1회씩 + backward 1회 → `Σ_{s,d}(a_u^clean − a_u^corrupt)·(∂m/∂t_v)`, 토큰 수로 나눈 뒤 프롬프트 평균 | edge 전체를 한 번에 |
| **CM-AP** (참값) | 문맥을 깐 상태에서 edge 하나만 토글해 **실제 patched forward** → logit-diff 차이, 프롬프트 평균 | **edge 당 forward 1회** |
| **ρ / r** (일치도) | edge 하나 = 데이터포인트 1개인 산점도의 상관계수 (순위 / 값) | — |

### 2.1 핵심 아이디어 — 재는 양은 그대로, **배경만 바꾼다**

기존 AP 와 CM-AP 는 **둘 다 "edge 하나의 한계 효과"** 를 잰다. 유일한 차이는 그 edge 를 재는 **배경(문맥)**:

| | 배경 (나머지 edge) | 재는 값 |
|---|---|---|
| **single-edge AP** | **전부 clean** | edge 하나를 corrupt 로 바꿨을 때의 metric 변화 |
| **CM-AP(d)** | **상위 d 만 clean, 나머지 corrupt** | 그 배경에서 edge 하나를 토글했을 때의 metric 변화 |

즉 CM-AP 는 회로의 성능(`m_d`) 자체를 재는 게 **아니다** — 그건 CPR 이 하는 일이다.
`m_d` 는 **기준점**일 뿐이고, 측정 대상은 그 기준점 위에서의 **edge별 기여도**다.

### 2.2 정의

```
문맥 C_d  : 상위 d 비율 edge 만 clean 유지, 나머지 전부 corrupt ablate
기준점    : m_d = metric(C_d)                       ← 재는 대상이 아니라 baseline

CM-AP(e | d) = m_d − metric(C_d \ {e})     (e ∈ C_d : 회로 안 → 빼본다, leave-one-out)
             = metric(C_d ∪ {e}) − m_d     (e ∉ C_d : 회로 밖 → 넣어본다, add-one-in)
```

부호 규약 통일: 두 경우 모두 **양수 = 그 문맥에서 중요한 edge**.
`d = 1` 이면 배경이 clean 모델이고 모든 edge 가 `C_d` 안이므로 **정확히 기존 single-edge AP 로 환원**된다.

### 2.3 왜 이렇게 구성했나 — 설계 결정별 근거

**(a) 왜 "배경"을 파라미터로 뒀나 — 두 regime 이 연속체의 양 끝이기 때문**

`d` 하나로 기존 AP(`d=1`)와 회로 ablation(`d→0`)이 이어진다. 별도의 두 지표를 만들면 값이 다를 때
"측정 방식이 달라서인지, regime 이 달라서인지" 구분할 수 없지만, **하나의 family 안에서 `d` 만 움직이면
차이의 원인이 regime 으로 특정**된다. 이것이 crossover 를 주장의 근거로 쓸 수 있게 하는 설계다.

**(b) 왜 하필 그 밀도들인가 — CPR 이 적분하는 구간이라서**

CPR 은 `PERCENTAGES = (0.001, 0.002, …, 0.5)` 에서 faithfulness 를 재고 **log 가중 적분**한다
(작은 회로에 큰 가중). `d ∈ {1, 0.5, 0.05, 0.005}` 는 기존 AP 끝점부터 CPR 의 주 가중 구간까지를
로그 간격으로 훑는다.

**(c) 왜 문맥을 "4기법 평균순위" 로 만들었나 — 순환 논리를 피하기 위해**

문맥을 특정 기법의 top-d 로 잡으면 그 기법이 자기가 고른 배경 위에서 평가받아 유리해진다.
반대로 문맥을 golden 기준으로 잡으면 golden 정보를 배경에 흘리는 셈이 된다.
**4기법 `|score|` 의 평균 순위**는 어느 한 기법을 우대하지 않으면서도 실제 회로에 가까운 구조를 준다.
(완전한 중립은 아니다 — §4.3-1 및 아래 (d) 참조.)

**(d) 왜 random 문맥도 같이 재나 — (c)의 잔여 순환성을 검증하려고**

consensus 문맥은 평가 대상 score 들의 blend 이므로 **부분적으로 순환**한다. 이를 확인하려 균등 랜덤
문맥을 대조군으로 넣었다. → 결과적으로 **random 문맥은 퇴화**했고(§3.1, `mean|I_ctx| = 0`),
이는 "구조 없는 문맥에서는 측정 자체가 불가능하다"는 별도의 발견이 되었다.

**(e) 왜 LOO / add-one-in 두 방향을 쓰나 — 회로 안팎이 서로 다른 질문이라서**

`d` 가 작아지면 대부분의 edge 가 회로 밖이 된다. 이때 회로 안 edge 에는 "빼면 얼마나 나빠지나"(LOO),
밖 edge 에는 "넣으면 얼마나 좋아지나"(ADD)를 물어야 **모든 edge 에 대해 정의**된다.
단 두 값은 **연산도 크기 분포도 다르므로 섞어서 집계하면 안 된다** → §3.2 에서 분리 보고.
그리고 **회로 발견이 실제로 묻는 것은 LOO** 다 ("선택된 회로 안에서 어느 edge 가 실제로 일하는가").

**(f) 왜 self-repair 문제가 완화되나**

single-edge AP 에서는 backup 경로가 살아 있어 한 edge 를 끊어도 보상이 일어나 기여가 가려진다
(실측: norm 매개 self-repair ≈ 효과의 14%). CM-AP 에서는 backup 이 `C_d` 밖이면 **이미 ablate 돼 있어**
그 은폐가 사라진다. 즉 **회로 ablation 이 실제로 만들어내는 조건**을 그대로 반영한다.

**(g) 왜 평가 edge 집합 `V` 를 이전 실험과 동일하게 뒀나**

`d=1` 결과를 **재측정 없이 그대로 재사용**해 crossover 의 출발점으로 삼기 위해서다
(`golden_ap_global_gpt2_ioi.pt` 의 랜덤 1000 + union 285 = 1,277개). 동일 표본이라 `d` 간 비교가 paired 다.

**(h) 왜 pruning 을 끄나**

patcher 의 `_prune()` 은 그래프에서 끊긴 edge 를 제거한다. 이를 켜면 edge 하나를 토글할 때 **연쇄적으로
다른 edge 까지 사라져** "한 edge 의 한계 효과"라는 정의가 무너진다. 따라서 CM-AP 측정에서는 끈다.
(CPR 평가는 pruning 을 쓰므로 이 점에서 미세한 차이가 있다 — §2.4 주석.)

### 2.4 실험 설정

**구성 절차** (`compute_cmap_gpt2_ioi.py`)

1. **평가 edge `V` 확정** — 이전 무편향 실험과 **동일한 1,277개**.
   `d=1` golden 을 재측정 없이 재사용하고, `d` 간 비교를 paired 로 만든다.

   **왜 1,277개인가** — 두 표본의 **합집합**이고 8개가 겹쳤다:

   | 구성 | 개수 | 목적 |
   |---|---|---|
   | 균등 랜덤 | 1,000 | 전 유효 edge(32,491)에서 무작위 → **모집단 무편향** |
   | 4기법 top-200 union | 285 | **중요 edge** 커버, 어느 기법도 자기 top edge 를 잃지 않음 |
   | 단순 합 | 1,285 | |
   | **중복 제거 후** | **1,277** | 랜덤 표본 중 8개가 union 에도 포함 |

   기대 중복수 `285/32,491 × 1,000 ≈ 8.8` 과 일치. golden 은 edge 당 한 번만 측정하고,
   집계 시 `in_rand`/`in_union` 두 마스크로 소속을 표시하므로 **겹치는 8개는 양쪽 표본에 모두 집계**된다
   (그래서 표에 랜덤 n=1000, union n=285 로 각각 나온다).
   상관계수(ρ, r)는 **이 1,277개 각각을 데이터포인트 1개로** 계산한다.
2. **consensus 순위 산출** — 4기법 각각 `|score|` 내림차순 순위를 매겨 **평균 순위**로 전 유효 edge(32,491) 정렬.
3. **문맥 `C_d` 구성** — 그 순위 상위 `d·N` 개를 clean 유지, 나머지를 corrupt ablate 하는 `in_graph` 마스크 생성
   (pruning 미적용). random 문맥은 같은 크기를 균등 랜덤으로.
4. **측정** — 배치마다 ① `m_d` 1회 ② `V` 의 1,277 edge 각각에 대해 해당 비트만 토글해 1회씩 patched forward.
   부호는 회로 안/밖에 따라 LOO / add-one-in 규약 적용. 100 프롬프트 평균.
   (조합당 7 batch × 1,278 forward ≈ 700초)
5. **집계** — 밀도 `d ∈ {1, 0.5, 0.05, 0.005}` × 문맥 {consensus} + `d=0.005` × {random}.
   지표는 `Spearman(score, CM-AP)` (주) 및 `ε = |score·T − CM-AP|` (보조).

**핵심 예측 (crossover)**: `d` 를 1 → 0.005 로 낮추면 어느 지점에서 **EAP 우위가 모듈 우위로 뒤집혀야** 한다.
뒤집히면 "모듈은 다른 regime 을 추정한다"가 직접 증명되고, CPR 결과가 독립적으로 설명된다.
(실제 결과는 §4.1~4.2 — **우위 소멸까지는 확인, 역전은 미확립**.)

> 구현 주의 ①: `_prune()` 미적용 (§2.3-h). CPR 평가는 pruning 을 쓰므로 미세한 차이가 있다.
> 구현 주의 ②: 사후 분석(`analyze_cmap.py`)에서 문맥 마스크는 **동일한 seed·정렬 규칙으로 재구성**해
> LOO/ADD 군을 복원한다.

## 3. 결과

### 3.0 스케일 처리 (읽기 전 필독)

score 는 per-token 정규화라 `×T` 로 단위를 맞췄다. 그러나 **CM-AP 의 golden 은 `d` 마다 스케일이 달라지므로**
`ε` 절대값 비교는 그 자체로 오염될 수 있다. 따라서:
- **주 지표 = Spearman** (스케일 불변, 그리고 **top-k 선택 자체가 스케일 불변**이라 회로 발견의 실제 요구와 일치)
- `ε` 는 보조. `fit slope` 이 1 에서 벗어나면 그 밀도에서 `×T` 가 옳은 변환이 아님을 뜻한다.

## 4. 분석

### 4.1 확인된 것 — EAP 의 우위는 regime 의존적이며 대량 ablation 에서 사라진다

세 모듈 **모두** 동일한 단조 패턴을 보인다 (LOO 군, vs EAP):

| | d=1.0 | d=0.5 | d=0.05 | d=0.005 |
|---|---|---|---|---|
| FrLN | **−0.092** `*` | **−0.048** `*` | +0.023 | +0.026 |
| SM | **−0.078** `*` | **−0.037** `*` | +0.007 | +0.028 |
| Bilinear | **−0.128** `*` | **−0.084** `*` | **−0.093** `*` | +0.051 |

- `d = 1, 0.5` 에서는 **EAP 가 유의하게 우세** (CI 가 0 을 제외).
- `d ≤ 0.05` 에서는 **그 우위가 사라진다** (FrLN·SM 은 부호가 뒤집히고 CI 가 0 을 포함).
- **3개 모듈이 독립적으로 같은 방향의 단조 변화**를 보인다 — 우연으로 보기 어려운 일관성.

→ **"single-edge AP 에서 EAP 가 이긴다"는 보편적 사실이 아니라 `d=1` 이라는 특정 regime 의 성질이다.**
기존 golden AP 로 모듈을 평가한 것은 **모듈에 불리하게 세팅된 한 점**에서만 측정한 셈이다.

### 4.2 확인되지 않은 것 (정직하게)

- **역전 자체는 통계적으로 확립되지 않았다.** `d ≤ 0.05` 의 양(+)의 차이는 **모두 CI 가 0 을 포함**한다
  (n = 162~314). "모듈이 CPR regime 에서 EAP 보다 낫다"를 이 실험만으로 주장할 수 없다.
  주장 가능한 것은 **"EAP 의 우위가 소멸한다"**까지다.
- **CM-AP 는 CPR 격차를 설명하지 못한다.** CPR 은 6.15 → 13~15 (**2배 이상**)인데, CM-AP 의 ρ 차이는
  ±0.03 수준이다. 즉 **CPR 이득의 원인이 "문맥 한계효과를 더 잘 추정해서"만은 아니다.** 다른 경로
  (예: FrLN 의 공통성분 제거로 인한 순위 정화, 또는 회로 선택의 집합적 성질)가 남아 있다.
- **작은 d 에서 신호 자체가 약하다.** `mean|I_ctx|` 가 d=1 대비 0.29× 로 줄고, ADD 군은 ρ≈0.06 로 무신호.
  d 를 더 낮추면(CPR 의 주 가중 구간 0.001~0.01) 측정 자체가 노이즈에 잠식될 위험이 있다.

### 4.3 부수 발견

1. **random 문맥은 퇴화한다** (d=0.005 에서 `mean|I_ctx| = 0`). 무작위로 0.5% 를 남기면 정보 경로가
   끊겨 모델이 완전 corrupt 와 구별되지 않는다. **문맥은 구조적이어야 한다** — 무편향성만 좇으면 측정 불능.
2. **Bilinear 의 반전 폭이 가장 크다** (−0.128 → +0.051, 총 +0.18). single-edge 에서 cross ≡ 0 이라
   최악이었다가 대량 ablation 에서 선두가 되는 것은 **§1.4 의 regime 설명과 정확히 일치**한다.
   (단 각 지점의 CI 는 넓다.)
3. **`ε` 의 겉보기 역전은 스케일 아티팩트였다.** d=0.005 의 `ε(×T)` 는 Bilinear 가 최소(0.0222)로 보이지만,
   `fit slope ≈ 0.25` — 그 밀도에서 `×T` 변환이 4배 어긋난다. 재스케일 후에는 네 기법이 0.0127~0.0137 로
   사실상 동률이다. **스케일 불변 지표(ρ)를 주 근거로 삼은 이유.**

### 4.4 결론

> **CM-AP 는 기존 single-edge AP 가 `d=1` 극단이라는 점을 드러내고, `d` 를 낮추면 EAP 의 우위가
> 유의하게 소멸함을 보인다.** 이는 "기존 golden 이 회로 발견 regime 을 대표하지 못한다"는 §1.4 의 주장을
> 실증한다. 다만 **모듈의 우위로의 역전과 CPR 격차의 설명은 이 실험으로 확립되지 않았다** —
> 회로 발견 성능의 주 근거는 여전히 CPR 이고, CM-AP 는 **golden 선택의 타당성에 대한 진단**으로 쓰는 것이 옳다.

### 4.5 남은 작업 (원한다면)

- `d ∈ {0.02, 0.01}` 추가 → 교차 구간 해상도 향상, 단 신호 감쇠 한계 확인 필요
- LOO 군 표본 확대 (현재 162~314 → CI 축소)
- `gemma2` 반복 — CPR 이득이 훨씬 큰 모델(6.6→22)에서 더 큰 효과가 관측되는지
- FrLN 의 CPR 이득에 대한 별도 가설(공통성분 제거) 직접 검증
